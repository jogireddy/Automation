# LearnPlaywright - JavaScript and Playwright Learning Repository

This repository is a hands-on learning workspace for JavaScript fundamentals, object-oriented programming, async programming, TypeScript, and Playwright automation testing.

## What’s Included

- JavaScript basics and core concepts
- Arrays, objects, functions, callbacks, promises, and async/await
- OOP topics such as encapsulation, inheritance, and polymorphism
- TypeScript fundamentals and interfaces
- Playwright fundamentals and sample test automation scripts

## Getting Started

1. Clone the repository.
2. Install dependencies:
   ```bash
   npm install
   ```
3. Install Playwright browsers:
   ```bash
   npx playwright install
   ```
4. Run Playwright tests:
   ```bash
   npx playwright test
   ```

## Topics Covered

- Variables and scope (`var`, `let`, `const`)
